## 你好，我是 Xuan

一个程序员，也对产品、设计和写作感兴趣。

白天写代码，晚上读书。喜欢把复杂的东西拆开、讲简单；也喜欢把模糊的想法写下来，看看它到底站不站得住。

这个博客是我的公开笔记本。不是教程站，也不是新闻站，只是把一些想清楚了、或者还没完全想清楚的东西放在这里。

## 这里会写什么

- **技术笔记**：Web、工具链、AI，以及那些踩过的坑。
- **产品与设计**：一个功能为什么这样做，以及它还可以怎样。
- **阅读与随笔**：书、电影、生活里的一些片段。

更新不定期。写得动就写，写不动就不写。

## 关于这个站点

这个博客用 [Hugo](https://gohugo.io/) 生成，主题是 [PaperMod](https://github.com/adityatelange/hugo-PaperMod)，托管在 GitHub Pages 上。

整站是纯静态的：没有数据库，没有评论系统，也没有广告。文章源码都在 GitHub 上，改一个 Markdown 文件，推上去，一分钟后就更新了。

如果你也想搭一个，我写了一篇完整的教程：[用 Hugo + GitHub Pages 搭一个博客](/posts/build-a-blog-with-hugo/)。

这句话一直放在我的编辑器里。希望这个博客也能保持这种状态：先写，再想清楚。
