Markdown 的好处是：写的时候只关心内容，排版交给渲染器。这篇既是小抄，也是这个博客的排版测试页。

## 标题

用 `#` 到 `######` 表示六级标题。一篇文章只用一个一级标题，正文从二级开始。

```markdown
## 二级标题
### 三级标题
```

## 强调

```markdown
**加粗**
*斜体*
~~删除线~~
`行内代码`
```

效果：**加粗**、*斜体*、~~删除线~~、`行内代码`。

## 列表

无序列表：

```markdown
- 第一项
- 第二项
  - 嵌套一项
```

- 第一项
- 第二项
  - 嵌套一项

有序列表：

```markdown
1. 先这样
2. 再那样
3. 最后这样
```

1. 先这样
2. 再那样
3. 最后这样

任务列表：

```markdown
- [x] 写完初稿
- [ ] 通读一遍
- [ ] 发布
```

- [x] 写完初稿
- [ ] 通读一遍
- [ ] 发布

## 引用

```markdown
> 写作不是把想清楚的东西写下来，
> 而是通过写，把东西想清楚。
```

> 写作不是把想清楚的东西写下来，
> 而是通过写，把东西想清楚。

## 链接与图片

```markdown
[链接文字](https://example.com)
![图片说明](/images/example.png)
```

链接会自动加下划线，图片会自适应内容宽度。

## 表格

```markdown
| 工具 | 语言 | 特点 |
| --- | --- | --- |
| Hugo | Go | 构建快，单二进制 |
| Hexo | Node.js | 主题多，中文资料多 |
```

| 工具 | 语言 | 特点 |
| --- | --- | --- |
| Hugo | Go | 构建快，单二进制 |
| Hexo | Node.js | 主题多，中文资料多 |

表格在手机上容易挤，列不要太多。

## 代码块

带语言标记的代码块会启用语法高亮：

````markdown
```python
def greet(name: str) -> str:
    return f"Hello, {name}!"
```
````

```python
def greet(name: str) -> str:
    return f"Hello, {name}!"
```

行内代码适合写 `git push`、`baseURL` 这种短词。

## 脚注

```markdown
Hugo 的构建速度很快[^1]。

[^1]: 官方基准里，几百篇文章通常也只需要几百毫秒。
```

Hugo 的构建速度很快[^1]。

## 写在最后

语法不用背。写多了，常用的那几个自然会留下。真正重要的是：**先把想法写出来，再考虑排版**。
