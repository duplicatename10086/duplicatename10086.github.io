信息流里的表达，很多时候是即时的：看到一句话，转发；有一个念头，发一条动态。它们很轻，也很容易消失。

博客不太一样。它要求你把一个想法放一放，想清楚，再写下来。哪怕只有几百字，也是在把散落的东西整理成可以被未来的自己重新读到的形状。

所以我决定开一个自己的博客。

## 这里会写什么

大概会是三类东西：

- **代码**：做过的小项目、踩过的坑、最近学到的东西；
- **阅读**：读完一本书之后留下的笔记，而不是书摘的堆叠；
- **生活**：一些还没有结论的观察，和偶尔的碎碎念。

它们不一定每篇都“有用”。但我希望它们都是诚实的。

## 为什么是 Hugo

选择 Hugo 的原因很实际：

1. 它是一个单独的二进制文件，不需要装 Node.js 或 Ruby；
2. 构建很快，几百篇文章也是眨眼的事；
3. 生成的是纯静态 HTML，交给 GitHub Pages 托管，不花钱，也不用维护服务器。

写作本身只需要一个 Markdown 文件。剩下的交给构建流程。

## 写多慢算多慢

我不打算给这个博客定更新频率。比起“每周一篇”，我更想要“每篇都值得留下来”。

如果一篇文章写到一半发现没什么可说，那就让它留在草稿里。写作的第一读者是自己，先让自己愿意重读，再谈别的。

## 从这一篇开始

这是第 0 篇。之后的内容，会慢慢长出来。

如果你也在犹豫要不要开始写，不妨先写下自己的“hello world”——不用等想清楚，先让第一行字出现。
